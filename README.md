# Prior Authorization Story Simulator

Day 27 of the #60DayClaudeChallenge

## Project Overview

This project is an interactive story-based simulator designed to explain the Prior Authorization (PA) process in healthcare.

Users follow Rahul's journey as he navigates diagnosis, insurance review, denial, appeal, and final approval for a specialty medication. Priya guides the user throughout the experience with explanations and insights about each stage of the process.

## Features

* Interactive healthcare journey
* 8 story chapters
* Progress tracking
* Decision-based exploration
* Educational explanations
* Approval and appeal workflow
* Restart functionality
* Responsive design
